ADHD map

An explorable map of ADHD symptoms, the triggers that make them worse, the strategies and treatments that help, and the impacts they have. Click a node to open it and reveal what it is connected to.

Prototype A: Cytoscape.js

Tidy diagram. Each expansion re-runs the fcose layout and the map settles into a still picture.

Prototype B: force-graph

Live physics. Nodes drift and settle in a running force simulation, and can be dragged and pinned.

Both prototypes read the same data/adhd-map.yaml file and share the same expand and collapse logic, so only the rendering differs.
